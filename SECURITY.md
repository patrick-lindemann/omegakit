# Security policy

Report a vulnerability privately through GitHub:
[Report a vulnerability](https://github.com/patrick-lindemann/omegakit/security/advisories/new)
on the repository's Security tab. Please do not open a public issue.

Fixes go into the latest release only.

omegakit is not meant for untrusted configs: loading, validating and checking a
config import and run code. The
[Security](https://omegakit.readthedocs.io/en/latest/security/what-runs/) page of the
documentation lists what runs, and reports about behaviour it already describes are not
vulnerabilities.
